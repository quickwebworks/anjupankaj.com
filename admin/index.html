From SQL file to reviewed content

  1. Export the original WordPress database as UTF-8 SQL from phpMyAdmin. Plain CREATE TABLE and INSERT INTO … VALUES dumps are supported, up to 400 MB. Individual SQL statements must be under 32 MB.
  2. Select the file and confirm the source URL, table prefix and date range. Compressed files, INSERT … SELECT, binary dumps and nonstandard SQL are not supported.
  3. Analyse the file. Review posts, featured image mappings, categories and media paths.
  4. Export the normalized migration JSON. No tables, users, credentials or scripts are executed.
  5. To save posts, sign in as a publication admin and run the database import. Original media URLs must remain reachable; reachability is not checked by this preview.
The SQL file can contain sensitive data. Prefer a content-only export. This tool reads it locally, ignores users/options, and does not send the file to a server.
